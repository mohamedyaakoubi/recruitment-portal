# Design Concept for Candidate Application Form

## Visual Style Analysis from International Skills Website

Based on the provided International Skills landing page screenshot, the design follows these key characteristics:

### Color Palette
- **Primary Blue**: Deep navy blue (#1B365D or similar) - used for header and main navigation
- **Secondary Blue**: Bright blue (#0066CC or similar) - used for buttons and accents
- **White**: Clean white background for main content areas
- **Red Accents**: Red elements for highlights and decorative elements
- **Text Colors**: Dark gray/black for main text, white for navigation text

### Typography
- Clean, modern sans-serif fonts
- Bold headings with good contrast
- Professional and readable text hierarchy

### Layout Structure
- **Header**: Dark blue background with logo on left, navigation in center, contact info and language selector on right
- **Main Content**: White background with centered content
- **Visual Elements**: Circular profile images, decorative geometric shapes, professional photography
- **Search/Action Area**: Prominent search functionality with blue button

### Key Design Elements
1. **Logo Placement**: Top-left corner in header
2. **Navigation**: Horizontal menu in header
3. **Contact Information**: Phone and email prominently displayed in header
4. **Professional Imagery**: Circular cropped photos of professionals in various fields
5. **Geometric Accents**: Red and blue geometric shapes for visual interest
6. **Clean Forms**: Simple, well-spaced form elements
7. **Call-to-Action**: Prominent blue buttons

### Responsive Design
- Mobile-friendly layout
- Scalable elements
- Touch-friendly interface elements

## Application to Candidate Form

### Header Design
- Dark blue header with International Skills logo
- Contact information display
- Clean, professional appearance

### Form Styling
- White background with subtle shadows/borders
- Blue accent colors for form elements
- Proper spacing and typography
- Professional button styling

### Footer Design
- Company contact information
- Social media links
- Professional layout matching header style

### Color Implementation
- Primary: #1B365D (dark blue)
- Secondary: #0066CC (bright blue)  
- Accent: #DC3545 (red)
- Background: #FFFFFF (white)
- Text: #333333 (dark gray)

### Typography
- Font family: System fonts (Arial, Helvetica, sans-serif) or similar clean sans-serif
- Proper font weights and sizes for hierarchy
- Good contrast ratios for accessibility
